# Лендинг «Корпорація ЕНСІ» — дизайн

Дата: 2026-09-11

## Мета

Перенести Figma-макет (файл `EWzS2hmO4dVdqKRt4nyTUF`, фрейми `UA_Desktop_Home_1440` і
`ENG_Desktop_Home_1440`) у робочий сайт, який хоститься на GitHub Pages.

## Рішення, узгоджені з користувачем

- Стек: Vue 3 + Vite, без TypeScript, без роутера, без UI-бібліотек.
- Три макети з Figma: телефон 390 (до 767px, базові стилі), планшет 768 (768–1439px, колонка 768px по центру),
  десктоп 1440 (від 1440px, точні координати). Фони секцій і шапки завжди на всю ширину екрана.
- Меню: телефон — лише логотип і перемикач мови; планшет — «Про нас», «Контакти», мова; десктоп — повне.
- Кожна секція займає екран: hero не нижче 900px і не нижче 100vh; «Про нас» і «Контакти» не нижче 705px
  і не нижче 100vh мінус висота шапки (195px), їхній 705px-кадр центрується по вертикалі.
- Шрифт заголовків Nekst замінено на Geologica (Google Fonts). Основний текст — Inter (Google Fonts).
- Обидві мови (UA, EN) в одному застосунку, перемикаються без перезавантаження.
- Деплой: GitHub Actions збирає проєкт і публікує на GitHub Pages при push у `main`.

   шапка видима, але з прозорим фоном; білий фон з'являється при першому ж скролі. Зліва логотип (SVG, свій для кожної

## Структура проєкту


## Дані

Всі тексти лежать у `src/i18n.js` як об'єкт `{ ua: {...}, en: {...} }`. Компоненти отримують
поточний словник через `provide/inject`. Вибір мови зберігається в `localStorage` під ключем
`ensi-lang`, за замовчуванням `ua`.

## SEO

При збірці сторінки пререндеряться через vue/server-renderer: `/` українська, `/en/` англійська; клієнт гідрує
розмітку. У head: title/description обома мовами, canonical, hreflang uk/en/x-default, Open Graph з og.jpg 1200×630,
JSON-LD Organization, favicon.svg. Плагін у vite.config.js генерує robots.txt і sitemap.xml. Абсолютна адреса — `VITE_SITE_URL`.

## Обробка помилок

Сайт статичний, зовнішніх запитів окрім Google Fonts немає. Якщо шрифти не завантажились,
працює системний fallback (`sans-serif`). Некоректне значення в `localStorage` ігнорується,
береться `ua`.

## Перевірка

- `npm run build` проходить без помилок.
- Візуальне порівняння зібраної сторінки на ширині 1440 зі скріншотом макета (обидві мови).
- Перемикач мови міняє всі тексти, включно з меню і назвою компанії.
- Посилання меню скролять до правильних секцій.
- Workflow деплою успішно публікує сайт після push у `main`.
