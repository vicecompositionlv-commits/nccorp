# Лендинг «Корпорація ЕНСІ» — дизайн

Дата: 2026-09-11

## Мета

Перенести Figma-макет (файл `EWzS2hmO4dVdqKRt4nyTUF`, фрейми `UA_Desktop_Home_1440` і
`ENG_Desktop_Home_1440`) у робочий сайт, який хоститься на GitHub Pages.

## Рішення, узгоджені з користувачем

- Стек: Vue 3 + Vite, без TypeScript, без роутера, без UI-бібліотек.
- Тільки десктоп. Контент-контейнер 1312px по центру, макетна ширина 1440. Медіазапитів немає.
- Шрифт заголовків Nekst замінено на Onest (Google Fonts). Основний текст — Inter (Google Fonts).
- Обидві мови (UA, EN) в одному застосунку, перемикаються без перезавантаження.
- Деплой: GitHub Actions збирає проєкт і публікує на GitHub Pages при push у `main`.

## Структура проєкту

```
ЕНСІ/
  index.html
  package.json
  vite.config.js         # base береться з імені репозиторію в GitHub Actions
  .github/workflows/deploy.yml
  public/assets/         # hero.png, contacts.png, logo.svg, mark-nc-*.svg, icon-*.svg
  src/
    main.js
    App.vue              # композиція секцій, стан мови
    i18n.js              # словник текстів UA/EN, збереження вибору в localStorage
    styles/global.css    # шрифти, reset, змінні кольорів
    components/
      AppHeader.vue
      HeroSection.vue
      AboutSection.vue
      ContactsSection.vue
```

## Дані

Всі тексти лежать у `src/i18n.js` як об'єкт `{ ua: {...}, en: {...} }`. Компоненти отримують
поточний словник через `provide/inject`. Вибір мови зберігається в `localStorage` під ключем
`ensi-lang`, за замовчуванням `ua`.

## Обробка помилок

Сайт статичний, зовнішніх запитів окрім Google Fonts немає. Якщо шрифти не завантажились,
працює системний fallback (`sans-serif`). Некоректне значення в `localStorage` ігнорується,
береться `ua`.

## Перевірка

- `npm run build` проходить без помилок.
- Візуальне порівняння зібраної сторінки на ширині 1440 зі скріншотом макета (обидві мови).
- Перемикач мови міняє всі тексти, включно з меню і назвою компанії.
- Посилання меню скролять до правильних секцій.
- Workflow деплою успішно публікує сайт після push у `main`.
